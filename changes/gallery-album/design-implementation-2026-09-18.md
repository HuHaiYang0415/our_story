# 相纸页局部设计记录

本记录描述相纸页当前源码；[PRD v2.1](PRD-2026-09-18.md) 与 r2 是历史方向参考。范围与发布许可只以 [SCOPE.md](../../SCOPE.md) 为准，不替代 [DESIGN.md](../../DESIGN.md)。根级设计文档合并待用户确认；其他页面与全站设计体系不在本次修改范围。

## Overview

**Creative North Star: "窗边暖纸邮册"**

当前修订为用户精确细化后的五组邮册。沿用暖纸、叶影、镂空邮票纸框和手写题签，让真实照片主导体验；下方所有旧批次只作历史，不约束当前实现。

**Key Characteristics:** 一册一封面；首次轻提、再次开册；单视口；连续城市地图；原图无框。

## Colors

印记色承担主强调；暖白地面与奶油纸面是中性材料，深棕文字、柔棕辅助文字与纸边线承担信息层级。规范值见 frontmatter，证据为 `Cabinet/src/pages/gallery/gallery.css`。

**The Light Leaf Rule.** 此页日夜使用同一浅色调色板与静态叶影，不继承全站夜间深色材料，也不滤色真实照片。

## Typography

标题使用站点衬线变量，手写题签使用自托管 Long Cang 子集 `Gallery Hand`（400，字体 7,520 bytes），事实与操作文字保持紧凑层级。题签在手机降至 1.1rem、短屏降至 .875rem；这是响应式角色变化，不是等比字号梯级。

**The Separate Facts Rule.** 题签与计数分行；只显示明确提供的日期，缺日期直接省略，不补推断日期或“小记”。

## Layout

单视口椭圆封面轨道延续桌面九张／手机五张邻近容量；当前只有五册。安全区及主题拨盘留位保持，观看底部为横向缩略图条，原生 pan-x 与点击跳图不改变册边界；首尾有限、不循环、不跨册，Ctrl/Cmd 滚轮保留浏览器缩放。

## Elevation & Depth

纸纤维、柔和投影与前后遮挡延续现有材料层次。

**The Lift Then Open Rule.** 任意封面第一次激活即移到前景中央并上提（16px）选中，第二次独立激活才开册；没有聚焦全屏阶段或“进入”按钮，减少动态偏好停用过渡。

## Shapes

封面保留镂空邮票纸框、纸签与珊瑚票根；地图封面为圆形定位标。观看当前原图的容器透明、无相纸框与纸面垫底，保留原比例与原色。

## Components

五组已确认内容按 `Cabinet/src/pages/gallery/data/galleryContent.ts` 顺序记录：迪士尼 72 张，封面 `1000013716.jpg`，日期 2026-09-13；告白 1 张，封面 `2026-06-26.jpg`，日期 2026-06-26；节日 2 张（`2026-05-20.jpg`、`七夕.jpg`），封面 `七夕.jpg`，无组日期；灵隐寺 1 张，封面 `2026-03-14.jpg`，日期 2026-03-14；日常 11 张，封面 `1000013424.jpg`，无组日期。共 87 张，全部已确认文件名与顺序以该源码清单为准，不复制私人地址到此记录。

**The Small Until Current Rule.** 封面、地图定位标及条带统一使用长边最多 400px、JPEG q60、空 EXIF 的小图，均延迟加载；87 张合计 1,449,149 bytes。只为册内当前大图请求原始字节，原文件合计 789,232,466 bytes，不预载下一张。当前源码通过 `resolvePublicAssetUrl()` 解析静态 `gallery/originals/<slug>/<fileName>` URL；没有 medium/large 派生观看层。失败仅手动重试，恢复时先归还舞台焦点，Escape 可返回，没有静默重试。

**The City Means City Rule.** 地图只有全国／城市两层，共用中国投影，34 个全国区域持续挂载；上海 16 区与浙江 11 市使用固定 ECharts 4.0.2 BSD 3-Clause 数据，最大缩放 40。同城代表点聚合为带计数的封面定位标，锚点旁分页选择邮册；地址只在城市附近展示，不做街道精确定位、不推断私人坐标、不向第三方发送地址。选册不新增地图层级或继续放大；观看返回保留视域。地图控件使用 SVG 图标。

## Do's and Don'ts

Do 延续浅色叶影、纸物封面与无框原图的角色分工；Do 保留明确日期、册内顺序、有限边界和手动重试。Don't 将城市代表点描述为门牌定位；Don't 将分组确认本身视为发布批准。用户于 2026-09-18 另行明确批准公开五册共 87 张原图，并提供展示地址；当前源码五册均标记为 public。界面已移除“本地素材 · 未发布”。即将组装的隔离发布排除七夕专题与本地测试 UI（节日相册中的既有照片仍属于已批准的 87 张）；根设计合并边界未变。本记录不宣称隔离发布已推送、上线或获得新一轮审阅；既有验收段落仅覆盖其注明的历史批次，本次文档更新未重跑 UI 验收。

当前验收：主代理最终五视口 QA、十个模型／地理测试及重试焦点修改后的 `npm run verify` EXIT 0 全通过。最新截图为 `.impeccable/review/gallery/{1440x900,390x844,360x640,768x1024,844x390}-{landing,viewer,national,city}.png`，另有丽水状态；矩阵见 `latest-results.json`。独立审阅仅将封面延迟加载／地图 SVG 两项修正评分为 resolved，结论 scoped SHIP，不是整页新一轮审阅保证或发布许可。

有限原图错误恢复尾部检查现已 EXIT 0：指针首次上提／再次开册、仅手动重试、重试恢复舞台焦点与 Escape 返回、减少动态、200% 字体说明包含且文档滚动为零；DNS rebinding Host 防护用 `node:http` 验证 403（Fetch 忽略 Host 覆写，不能用于该断言）。这些是主代理完成的结果，本次仅文档修改未重跑 UI 测试。

未规范化：旧批次临时两册各五张、聚焦阅读／小记、medium/large 与深色夜间材料、第三地图层及私人门牌精度均不是当前系统；历史测试缺陷与等待策略不成为未来界面规则。

## 历史修订：连续地图与一册一入口

以下为已被当前五组／两层地图修订取代的历史实现事实。历史笔记和素材来源保留，不作为当前交互、内容或验收约定。

全国 → 城市 → 地点始终使用同一连续中国投影。34 个省级边界持续挂载，放大上海时保留周边；上海 16 区通过 `parseGeography(value, 16, china.project)` 叠加，迪士尼公开轮廓的 241 个坐标也使用该投影，不另行拟合孤立城市。地图舞台透明，深层行政区不填色；世界、圆形封面定位标和标签同步使用 480ms 缓动，拖动立即响应，减少动态偏好停用过渡。仅读取本地地图文件，不接入在线 API、瓦片或私人地点推断。

圆形封面锚定已确认的地理位置，显示提供的地点文字。`groupAlbumPins()` 将相同世界坐标聚合为一个带计数的定位标；锚点附近的选择器按常规三本、中等高度两本、短屏一本分页，所有邮册可达，不设固定侧栏。未提供明确地址的日常邮册保持未定位。选择地点前保存城市视野，页头“回到上海”恢复该视野；从观看返回地图保留精确视野。短横屏的未定位入口放在左上，避开地点入口。

首页一册一个封面入口，聚焦后独立激活进入本册。册内底部为左右横向缩略图条：原生 `pan-x` 滑动只移动条带，点击直接跳到照片，Ctrl/Cmd 滚轮保留浏览器缩放；主图继续使用自定义组内滑动，首尾不循环、不跨册。题签与照片计数分行。封面和条带使用 thumb、聚焦使用 medium、观看仅加载当前照片 large；large 是长边最高 2048px 的派生 JPEG，不是未经处理的原始文件。页面保持单视口，无纵向滚动。

当前仅两本 DEV 测试邮册，各五张：日常为原顺序前四张加既有 `1000013424` 封面，保留原相对顺序；迪士尼为原顺序前五张。正式分组、封面、名称和地址仍待用户整理。完整 87 张资产及 261 个派生图未改，生产公开相册集合仍为空；测试内容不构成正式确认。

主代理在全部 UI 修改后完成 `npm run verify`（EXIT 0）、九个模型/地理测试、第二轮五视口八状态矩阵、13 本同城未细分及 13 本同公开地点的桌面/手机 fixtures；360/390 宽 CDP 触摸横滑通过且不改变当前主图。最新帧与结果位于 `.impeccable/review/gallery/`，这些模拟结果不替代真机检查。本次文档补丁未重跑测试。

200% 长小记首轮出现一次等待超时；续跑仅增加聚焦状态就绪等待及 520ms 门禁等待，独立尾部 EXIT 0。`tail-results.json` 明确为 `independent-tail-only`，只覆盖 200% 长小记、手动图片恢复、参考尺寸和夜间轨道/聚焦，不重新认证主矩阵。最终 SHIP 审阅仅限七项修正：同坐标多册可达、城市视野返回与连续过渡、短横屏避让、深层填色接缝、日常封面包含在五张内、题签/计数分行、条带原生横滑；审阅排除该独立 200% 尾部检查，其功能检查另行通过。没有 `build:site`、发布或提交。

未规范化：DEV 临时标题、封面与地点文案不成为正式内容规则；尾部等待超时是测试过程记录，不成为界面设计规则。实现与验收详情继续见 [实施记录](implementation-2026-09-18.md)，地理边界与来源见 [地图说明](../../Cabinet/src/pages/gallery/map/README.md)。

## 历史批次笔记

下列段落按实施过程保留；交互、照片数量与审阅范围均以上方当前系统记录为准，仍有效的材料与来源指针保留。

## 体验与层级

浏览是单屏椭圆轨道，桌面最多九张、手机最多五张邻近邮票；没有持续自转、浏览箭头、圆点或底部控制条。第一次激活聚焦所选相纸，完成过渡后的第二次独立激活进入本册观看。来源轨道退后并隐藏所选照片的重复副本；返回逐层恢复来源位置。

聚焦保留相纸身份：照片下方纸带内的手写题签、珊瑚色票根与邮戳；日期和操作位于纸外。题签使用自然高度，两行文字不覆盖照片窗口。观看阶段简化为大图、必要事实与本册计数，首尾不循环、不跨册。

地图使用省级真实边界及已确认的展示点，候选封面复用同一观看流程；保留地图视域与候选位置。小记和筛选使用同屏分页，不以省略或内部纵向滚动替代内容。

## 视觉材料

沿用站点暖纸与木色语境。日间纸面为 `#fff8ed`，辅助文字为 `#73604f`，纸边线为 `#d8c4ac`，印记为 `#a95f47`；主文字与舞台底色优先继承站点变量。夜间局部底色为 `#191511`、纸面为 `#3a3027`、主文字为 `#f3e8d8`。夜间装饰处理不滤色真实照片。

四个 WebP 装饰分别承担纸纤维、镂空邮票纸框、纸签按钮和票根。地图预览也实际绘制纸纤维，而非仅保留 CSS 声明。邮戳与标题小菱形为代码原生几何。照片保持原比例和原色，不生成私人照片。

题签使用自托管 Long Cang 局部字符集 `Gallery Hand`，后备为楷体及既有手写字体；标题和正文继续使用站点字体变量。字体许可、素材来源和生成提示词见 [素材登记](../../Cabinet/src/pages/gallery/assets/README.md)。

## 输入、适配与可访问性

横向拖动、舞台滚轮和键盘操作具有对应路径；拖动不误触进入，Ctrl/Cmd 滚轮保留浏览器缩放。没有持续自动运动，支持减少动态效果偏好。按钮保留语义与可见焦点，主要操作目标至少 44px；错误由用户手动重试，不自动循环请求。

页面与功能文字层不纵向滚动，手机预留全站主题拨盘空间；短横屏采用局部横向排布。回归覆盖 360×640、390×844、768×1024、1440×900、844×390，以及 200% 文字缩放和长小记。这些结果不替代真实触控设备检查。

模型测试、五尺寸浏览器回归和 `npm run verify` 均通过；详情见 [实施记录](implementation-2026-09-18.md)。仅本地源码及验收构建，未发布；草稿相册仍仅 DEV 预览。

## 背景细化：窗边午后

用户随后指出参考图中的叶影及日常背景未体现，并要求简约温馨的优化。局部背景先复用既有纸纤维，增加静态、柔焦的斜向窗光和低对比暖色照明；观看与阅读阶段减弱光影，夜间不显示日照。所有环境层均在纸物后方，不染色照片、不参与点击，不增加动画或第三方依赖。

第一批背景细化时有机叶影待用户提供。内置生成尝试因额度上限失败，未生成新文件；用户要求后续先提供提示词，由其生成后上传，因此没有下载图库图片、截取参考图或用 CSS 几何假叶片代替。

待提供图片的提示词：横向 3:2，俯拍的暖白纸面或细腻浅亚麻表面（`#FDFBF7`）；左上角及左侧约 30% 区域有窗外枝叶投下的柔焦阴影，叶片轮廓自然可辨、深浅不一，植物本身不可见；右上方有柔和午后日光，中央和右侧约 60% 保持干净留白。低对比、温馨日常、真实摄影质感。不要照片、相框、人物、桌面道具、文字、水印或重复叶片图案。只生成背景，不生成网页界面。建议 1536×1024 或更高。

用户随后上传 `叶影.png` 并明确要求继续接入，现已导出 28,848 bytes 的 `leaf-shadow.webp` 用于背景。桌面浏览透明度 .72，聚焦 .55、地图 .42、观看 .32、阅读 .22；手机浏览 .55 并向照片所在区域渐隐。夜间不使用该日光叶影，保留既有纸纹与暖色环境底色。背景保持静态、不可交互，未修改真实照片。来源和机械导出事实见素材登记；用户实际使用的生成提示词未经确认。

## 地图分层与多邮册补充

后续用户明确要求先放大城市，再选择具体邮册定位地点，替代原先单册城市直接选册的流程。现为全国 → 城市邮册集合 → 具体邮册地点。城市集合使用四本一组（短屏两本）的同屏分页，不以地理封面堆叠承载全部邮册。背景舞台透明，地点层去掉大片区界填色，并补偿缩放后的线宽，叶影从标题到地图场景保持连续；城区文字避让拥挤标签。

上海提供有来源的 16 区边界，迪士尼提供公开园区轮廓和展示中心；只是邮册位置展示，不是导航地图或园内景点导览。缺少明确地点的日常邮册保持未定位。来源、许可和其他城市仍为省级细节的边界见地图实现说明。

缩略图浏览 → medium 聚焦 → large 进入观看的资源层级保留。日常 15 张和迪士尼 72 张分别由自己的照片集合供观看、保留顺序，不把册封面当成册内唯一照片。large 是长边最高 2048px 的高清派生图，不是仓库外未经处理的源文件；没有为此公开原始照片。最终五尺寸八状态回归、同城 13 本邮册桌面/手机测试、八个模型/地理测试及 `npm run verify` 均通过。主代理首轮批量检查后集中修复缩放线宽/填色和城区标签，第二轮确认后停止修饰。

# 相纸页 PRD v2.1：一屏之内，环绕的生活邮册

> 评审修订：用户要求移除浏览提示、左右箭头及其底部控制条；地图从中国全图开始，点击相册后放大到对应地点。其余方向暂时认可。本版落实这两项修订，仍是设计交付，不是已完成实现或发布许可。

## 1. 本轮结论与纠错

**设计主张：让照片成为有纸张厚度的邮票，在一座温暖、安静的数字展览中环绕展开。**

上一版 PRD 将相册设计为纵向收藏列表，允许首页、内页和说明区域滚动。这与用户要求的一屏体验冲突，是设计约束错误。本版明确撤销这些要求，并替代旧版的平面网格、多层标签和纵向分批加载方案。

用户本轮已明确：

- 所有页面状态保持一屏，不允许上下滚动。
- 邮册左右拖动浏览，电脑端鼠标滚轮转换为横向浏览。
- 不显示“左右拖动，慢慢翻看”等操作教程，不设置左右浏览箭头、分页圆点或底部浏览控制条。
- 邮票应呈现 3D 环绕、前后景深与尺度变化，形成数字展览感。
- 第一次点击邮票，出现大图与标题；再次点击才进入查看。
- 大幅减少标签层级，主要模式切换只保留地图入口。
- 地图首次进入显示中国全图；点击地图上的相册封面后，地图放大到该册有确认信息的更精确位置。
- 延续情侣手作、温馨治愈的材料与配色。
- 本轮先交付 PRD，再交付页面示意图；通过用户评审后，才交给执行会话开发。

本文件记录评审后的设计修订，不是已完成能力或发布许可。项目范围与正式基线仍遵循 [SCOPE.md](../../SCOPE.md)，共享风格与工程规范遵循 [DESIGN.md](../../DESIGN.md) 和 [AGENTS.md](../../AGENTS.md)。本版不修改其他页面。

本轮读取了当前源码、素材清单和执行任务。预览浏览器连接超时，没有完成当前页面的浏览器截图或滚动实测；以下判断来自源码和用户反馈。

- [galleryContent.ts](../../Cabinet/src/pages/gallery/data/galleryContent.ts) 已登记日常 15 张、迪士尼 72 张，共 87 张照片，并保留派生图地址和相册归属。

## 3. 对参考的实际转化

### 3.1 邮票/票根参考 → 可触摸的纸物

沿用用户提供的 PicSlicer 截图中“照片成为收藏物”的思路：纸边、票根虚线、日期题签、横竖相片、轻微厚度和叠放关系。

本版具体转化为：

- 外层展览使用有齿孔或票根缺口的照片邮票，照片占邮票正面的主要面积。
- 单枚邮票只选一种主边缘语言，不能同时叠加齿孔、胶带、蜡封、爱心、票号和多枚邮戳。
- 短题签印在纸上，少量日期印记跨纸边，但不盖住人脸和关键内容。
- 纸片之间通过前后位置、投影和视角建立空间，不通过增加卡片容器表达层级。

### 3.2 地图相册参考 → 另一种进入记忆的方式

延续 [Map for Love](https://github.com/WyankinzZ/map-for-love) 的地点与回忆关联、照片查看器独立于地图的思路。上一版的源码研究记录见 [2026-09-17 PRD](PRD-2026-09-17.md)。

本版将地图从后续增强提升为同轮设计范围：主舞台可以在邮册与地图之间切换。两者进入同一个聚焦状态和相册查看器，不建设另一套回忆数据，也不先出现地点管理列表。

### 3.3 新构图 → 立体环绕的私人展览

组成环绕关系的是纸质邮票：前景清晰、较大，侧面偏转，后景退远、较小。背景保持暖纸或浅亚麻感。

它应让人想到“把两人的相纸轻轻展开在眼前”，而不是机械唱片架、商场旋转广告、冷光科技展厅或平面卡片轮播。

## 4. 信息单位与内容组织

### 4.1 环绕邮册：一张照片是一枚邮票

沿用本轮示意图的组织方式。用户对其余方向暂时认可，未要求更改这一单位：照片作为环绕单位，同时保留按经历成组的关系。地图全国视图则按相册展示封面入口，避免同一册的多张照片堆满地图。

- 每枚邮票对应一个稳定照片 ID，并关联所属相册 ID。
- 第一次点击，展示这张照片、它的标题或所属相册标题，以及可选日期地点。
- 第二次点击，进入所属相册，并从这张照片开始观看。
- 主展览显示当前筛选范围内的照片；组内查看只遍历这本相册，不跨册混播。
- 环绕页与地图入口都使用同一相册/照片关系；“照片邮票”和“相册地图标记”是两种入口，不是两套内容。

### 4.2 标题与排序

- 标题优先使用已确认的照片短题；无短题时使用已确认相册标题，不强迫逐张编写，也不从文件名猜测。
- 环绕顺序在一个筛选结果内确定且稳定，不在每次渲染时随机洗牌。
- 默认按维护者确认的相册顺序和组内顺序展开；可在内容维护时编排不同日常/旅行片段的节奏，但不复制或新增内容。
- 日期、地点不完整时只显示已有事实，不为了印邮戳而编造精确日期。
- 日期沿用确认的精度：单日显示为“2026.09.13”，跨日显示起止范围，仅有月份则显示到月份。日期是日历事实，不做时区转换导致前后偏移；地点使用确认的展示名称，不强制要求坐标。
- 聚焦与查看态在标题下方保留一行日期/地点，缺哪项省略哪项；超长名称的全文仍可在同屏文字页阅读。
- 日常、旅行、约会共用一套展示方式，不再用常驻标签区分价值或重要性。

## 5. 不可变更的单屏契约

**所有状态都必须满足：页面根、页面槽、相册壳、展览舞台、聚焦层、相册查看器、地图、筛选层和文字阅读层均无纵向滚动。**

1. 使用动态视口与安全区适配；不能用固定桌面高度迫使手机产生溢出。
2. 浏览是场景中的位置/角度变换与内容切换，不是把宽内容做成原生横向滚动条；页面也不出现横向滚动条。
3. 不出现“加载更多”后向下追加、长照片网格、页面底部章节、抽屉内部纵向滚动或说明区滚动。
4. 一屏内容过多时依次减少装饰、减少同时可见邮票、切换照片/文字呈现，最后采用同屏分页；不能裁掉操作、压缩正文到不可读或隐藏真实内容。
5. 长注记、超长标题和完整说明使用同屏文字页，前后翻页阅读；不以省略号代替完整可达内容。
6. 200% 文字缩放与横屏短屏仍遵守相同契约。进入紧凑阅读模式时可减少或暂时隐藏照片，为文字与控件留出空间，不靠整体缩小解决。
7. 筛选项或同地点候选很多时采用少量选项分步选择/同屏分页；不把溢出转移到一个内层滚动区域。
8. 浏览器原生页面缩放、Ctrl/Cmd + 滚轮、辅助技术必须保留；不靠禁用缩放达成单屏。

这一契约是用户本轮对相册页的明确要求。执行会话不得以旧 PRD、现有壳层默认值或实现成本作为恢复纵向滚动的依据。

## 6. 一屏布局与视觉层级

### 6.1 桌面环绕浏览态

- **上方约 12%：**左侧共享返回，居中或略偏左的小标题“流光相册盒”；右侧一个“地图查看”纸签按钮。标题不做大幅宣传区。
- **其余可用区域：**环绕邮票舞台，是视觉主体。前景邮票靠中下部，侧向邮票逐渐缩小并偏转，后景邮票回到上部，构成可见的椭圆空间关系。
- **底部：**只保留纸面的自然留白与安全区，不预留浏览控制条。必要的“筛选”文字入口可低强调放在左下角；无教程、左右浏览箭头、圆点或序号条。

比例仅是构图参考，实施按可用宽高和安全区调整。返回、模式切换和筛选的位置稳定，不随邮票一起旋转。删除底部控制条后保持现有邮票构图，不用新增装饰填满留白。

### 6.2 3D 关系要求

- 桌面同时显示约 7–9 枚不同邮票：前景 1 枚，近侧各 1–2 枚，后景少量退远。移动端约 3–5 枚。
- 前景相对尺度约 1，近侧约 0.72–0.85，远处约 0.45–0.6；侧向偏转通常不超过约 35°，这些为视觉调校起点，不是未经验证的性能指标。
- 邮票沿连续空间轨道移动，而非几张相同大小卡片仅在 X 轴滑动；拖动中必须出现前后交换、透视和遮挡次序变化。
- 前景最清晰，后景可轻微降低清晰度和饱和度。景深辅助空间，不把后排处理成无法辨认的大块模糊。
- 邮票正面朝向观看者的可读范围，不展示镜像字；绕到背后不可见的节点应退场或循环复用位置，而不是暴露错误背面。
- 环绕是视觉连续性，不代表无限个内容。允许首尾循环，内部索引与读屏位置保持真实，不在主舞台常驻显示序号；任何时刻不在画面中同时出现同一照片的复制件。
- 只有 1–3 个结果时改为相应数量的疏朗弧形排列，不填充假照片。0 个结果使用单屏空态。
- 停止操作后缓和对齐最近的邮票，不持续自转，不产生弹簧反复回弹。

### 6.3 手作与色彩

- 继承全站暖白纸面、深木色文字与日夜主题；主背景参考 `#FDFBF7`，正文参考 `#2D241E`，优先使用现有语义令牌。
- 纸张边缘略不规则，有纤维、轻压痕和薄厚感；一处褪色朱印或手写题签提供个人痕迹。
- 背景是留有呼吸空间的暖纸/浅亚麻场，不铺满道具、书桌、夹子与花束；纸物本身是主角。
- 光照柔和偏暖，阴影随深度变化，不能给所有邮票套相同强阴影。
- 照片保留原色；夜间改变环境和纸面，不给照片统一染褐或强行压暗。
- 不使用霓虹、玻璃面板、多彩标签、仪表盘统计、大写拼音城市名或装饰英文。

## 7. 交互状态：浏览 → 聚焦 → 进入

### S0：环绕浏览

- 拖动舞台使邮票左右流动；鼠标滚轮和触控板输入具有相同浏览方向。
- 中央邮票自然对齐但不自动进入聚焦，更不自动进入相册。
- 点击一枚可见邮票触发 S1。后排邮票可被选中并移到前方；被完全遮住的邮票不能抢点击。

### S1：第一次点击，聚焦大图与标题

- 被选邮票离开环绕位置，正向移至中央并放大；后面的环绕场景降低存在感并停止移动。
- 同时展示大图、标题、可选日期地点，不增加“再点一次”等教学文案。
- 可提供语义明确的“进入相册”按钮作为第二次点击的等价入口，方便键盘和触控。
- 第二次独立点击聚焦图片/进入按钮才进入 S2；不是系统双击手势，不依赖双击速度。
- 第一次点击事件不能冒泡导致直接进入；快速连点在过渡完成前只按一次激活处理。
- 聚焦过渡结束后重新允许进入；关闭/返回、Escape 或点击明确的空白退出区域回到来源视图，并保留原位置。从邮册进入回 S0；从地图进入回地图及原候选照片。
- 在 S1 中使用方向键、滚轮或横向手势，可以切换聚焦照片，仍停留 S1，不自动进入；不显示左右浏览箭头。

### S2：第二次点击，进入相册单屏观看

- 环绕场景被同屏查看器替换；一屏主看一张照片，标题和短说明退为次要。
- 从刚才选中的照片开始，按其所属相册顺序向前/后观看，显示“当前张 / 本册总张数”。
- 切图直接使用拖动、滚轮和键盘方向键，画面不放左右箭头；角落的本册张数是内容位置，不组成底部操作条。
- 不再渲染组内网格，不需要向下滚动，不加一个强制的第四层大图弹窗。
- 照片完整比例展示。桌面可左右留白，手机可上下留白，不为了铺满而裁切。
- 较短文字与照片并列/上下排列；较长内容通过“读小记”进入同屏文字页，分页后返回同一张照片。
- 关闭查看器回 S1，再关闭聚焦回来源邮册或地图。页面左上明确写出“返回聚焦”“回到邮册”或“回到地图”，避免一次跳回展柜。
- 本册第一张和最后一张不循环，给出边界反馈；组内顺序与主环绕首尾循环分开定义。

## 8. 输入与防误触规则

### 桌面鼠标/触控板

- 舞台内普通滚轮向下 → 下一方向，向上 → 上一方向；空间表现为横向环绕平移。
- 触控板选取 X/Y 的主要轴作为一次意图，不把两轴相加造成斜向输入双倍加速。
- 普通滚动只在当前交互舞台内转换；控件、文字选择和浏览器缩放不被全局 wheel 处理器劫持。
- 在浏览态允许连续位移，停止后对齐；在聚焦/单张观看态按合理累计阈值切到相邻项，不能一格滚轮跨过多张。
- 采用与输入设备无关的速度上限与惯性衰减，鼠标和高频触控板都可精确停下。
- 水平拖动与点击须有位移阈值，建议起点为约 8px。超过阈值的手势只浏览，松手不能误打开邮票。
- 左右方向键提供等价浏览操作，Enter/Space 激活当前邮票；提供辅助技术可调用的前后动作与语义名称，不以常驻箭头呈现。Tab 不跟随所有后景卡片形成冗长焦点链。

### 手机触控

- 单指左右拖动环绕或切图；纵向手势不触发页面滚动，也不把整个视口拉出上下空白。
- 允许浏览器/系统必要手势及页面缩放，不强制关闭所有默认触控行为。
- 控件始终独立可点，主要热区至少约 44px。
- 单屏可见邮票数减少，中央邮票仍可辨认，不能把桌面九枚卡片整体缩小塞进手机。

### 焦点与动态效果

- 舞台以当前邮票为主要焦点对象，切换后适度播报标题和位置，不随每帧动画频繁播报；DOM/辅助阅读顺序应跟随内容顺序，不由视觉 Z 轴随机决定。
- S1/S2 使用正确的焦点进入、背景不可交互和焦点恢复；每层 Escape 只退一层。
- 减少动态效果时禁用惯性、长距离绕行和景深呼吸，保留静态前后关系与直接切换；仍然单屏。

## 9. 标签收敛与筛选

### 常驻界面

- 只保留一个视图切换纸签：邮册态显示“地图查看”，地图态显示“回到邮册”。
- 取消“按时间看/按地点找”双标签、生活标签长排、年份条、地点面包屑和主界面统计块。
- 筛选通过一个低强调“筛选”入口打开同屏小面板，默认关闭。

### 筛选面板

- 最多提供“相册”和“时间”两个维度；地点由地图承担，不重复增加多层地点筛选。
- 默认全部。每个维度只有在有区分价值时才出现；当前仅两册，不必强制同时展示多个维度。
- 项目多时采用短列表分页或分步选择，无纵向滚动。
- 应用后关闭面板，舞台重建当前结果并对齐第一项；清除后恢复全量内容。
- 已筛选时在入口附近显示一句结果摘要与清除动作，不生成一排可关闭标签。
- 结果为空时保留地图切换、返回和“清除筛选”，不显示一圈空邮票。

## 10. 地图查看：中国全图 → 相册所在地

地图属于本版设计范围，评审通过后与环绕邮册一起纳入执行，不再沿用上一版 P1 暂缓决定。

- **M0 全国态：**首次点击“地图查看”，舞台显示完整中国地图，暖纸底色、克制的省界和地名；全站返回与标题位置稳定，模式按钮改为“回到邮册”。不在刚进入时自动放大到已有照片最密集的城市。
- 全国地图按相册呈现小封面邮票，只使用确认地点。当前一册 72 张迪士尼照片在全国态仍对应一个相册入口，不展开为 72 个点。无坐标的相册不在地图上强行落点。
- **M1 定位态：**点击相册封面，地图在同一舞台中平移并放大到该册的更精确位置，同时呈现相册标题、日期、地点及照片候选。这个点击首先用于定位，不直接跳入大图查看器。
- 定位精度由已确认数据决定：有景点/街区坐标时定位到该范围；只有城市信息时到城市为止，不补造精确经纬度。一册包含多个地点时适配该册真实点位的范围，随后可以点击单个地点继续靠近。
- 地图放大保持相册标记可见，并为相册预览预留空间；正常动效建议约 400–600ms，减少动态模式直接切换视域。动画中连续点击只响应最后一次有效选中，不叠加多段飞行。
- 定位后在同屏相册预览中直接滑动候选照片；点照片进入 S1 聚焦，再次点击进入 S2。预览无左右箭头和滑动教程，不弹出纵向城市管理列表。
- 全国态同一城市的多本相册重叠时合为简洁封面叠片。点击先靠近该城市并分开展示相册，再选具体相册；不增加城市标签墙。
- M1 左上返回动作显示“全国”，一次回到 M0；M0 同一位置显示“返回展柜”。这个返回层级与右上“回到邮册”区分，不额外堆叠导航条。地图关闭预览、退出 S1/S2 时保留已选相册和已放大的位置，不突然重置。
- 地图可以在固定舞台内平移地理视域，这不等于页面滚动；页面边界与控件保持不动。
- 地图默认使用明确的加减按钮缩放；普通垂直滚轮在地图态仍映射为水平方向平移，避免与邮册模式产生输入冲突。触控双指地图缩放必须不影响外围页面与系统缩放约定。
- 无坐标的日常照片不伪造点位。底部提供轻量“没有标地点的日子”入口，切到这些照片的邮册视图；无坐标内容不丢失。
- “家里”等私人别名不推断住址；只有确认的展示级坐标才参与地图。
- 地图资源失败时提供重试与回到邮册。中国地图边界、地名和缩放底图使用同一套可靠地图数据；来源和许可在执行准备时核对。生成图只说明布局，不充当实际地图数据或精确点位依据。
- 邮册和地图各自记住浏览位置。首次进入地图是 M0；同次访问中切回地图恢复原视域，“全国”可显式复位。地图进入 S1 后只遍历已选相册/地点的候选；进入 S2 后按所属相册顺序查看，退出逐层恢复候选与视域。
- 不加入旅行达成率、天气、纪念日卡片和路径自动播放。日常与远方共享同一内容权重。

## 11. 适配、容量与资源预算

### 11.1 按宽度和可用高度共同构图

- 桌面：宽椭圆舞台，7–9 枚可见邮票；只有顶部小标题区，底部不设置浏览控件区。
- 竖屏手机：较窄环绕弧，3–5 枚可见；两侧退入景深而不是额外横向页面。
- 横屏短屏：缩短题签区、取消副句和非必要点缀，减少后景节点，为照片与返回控件留出空间。
- 200% 文字缩放：切换紧凑结构，完整文字必要时同屏分页；不让说明区滚动，也不在字体上反向缩放。

### 11.2 87 张及更多照片的呈现

- 全量内容形成稳定序列，舞台只挂载邻近的少量节点，禁止把 87 张中/大图同时放入 GPU 场景。
- 初次只加载可见邮票的缩略版本；临近浏览方向少量预取，聚焦才加载常规图，进入查看才请求大图。
- 复用现有稳定 ID、相册关系、thumb/medium/large 派生资源，不重新处理原图或更改来源。
- 位置变化以 transform/透明度为主，禁止每帧重排全体 DOM 或反复读写布局尺寸。
- 优先以现有 React/motion 与 CSS 3D 实现所需空间关系；确有必要再评估 WebGL。不可为本效果默认引入整套重型 3D 引擎。
- 阴影和景深效果有上限；低性能设备先减节点和模糊开销，保留单屏、层次与交互，不降级回长页面。
- 3D 不可用时采用单屏、有前后大小关系的静态弧形切换，仍保留双阶段点击。
- 不自动播放音乐、不持续自转；页面退出、失焦或遮挡时暂停无关动画、清理监听和资源任务。

### 11.3 加载、空态和失败

- 首屏先呈现可操作壳层与少量纸形占位，图片尺寸提前预留；占位不靠持续旋转吸引注意，也不产生页面跳高。
- 单张图加载失败只影响这枚邮票/这张照片，显示简短重试入口，仍可切换前后、退出或查看其他照片。
- 全部无内容时显示一张安静空纸签和返回入口；筛选无结果时提供清除筛选。不显示不可用的上传按钮或虚假照片。
- 未提供任何确认坐标时，地图态明确“还没有标地点的回忆”，提供回到邮册；不以虚构标记填充地图。
- 标题、照片或地点待确认的草稿仍遵循既有门禁；无内容和网络失败不混为同一种错误。

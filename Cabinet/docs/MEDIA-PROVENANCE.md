# 素材来源与隐私登记

此前任务没有新增图片、音频、字形或扫描件；七夕沿用工作区已有照片，并在任务9正式发布前补齐登记。本次 P0 相册新增的派生图片与来源、隐私处理见文末登记。现有专题素材继续由各自目录通过 Vite import 或 520 子页的目录资源加载。

## 新素材登记格式

新增素材必须在提交同一变更中补充以下字段：

| 字段 | 要求 |
| --- | --- |
| 路径与用途 | 记录仓库路径、页面/组件和展示尺寸 |
| 来源 | 自制、用户提供、公开素材库或生成工具；附原始链接/订单/授权记录 |
| 授权 | 许可类型、归属要求、是否允许商业发布和二次修改 |
| 压缩版本 | 记录原始文件是否留在仓外、发布文件格式、尺寸和体积 |
| 隐私评估 | 私人照片、笔迹、扫描件必须确认可公开范围、EXIF/个人信息清理和可读性 |
